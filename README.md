A Death Eaters membership form, created for entertainment purposes only.

## How to run

Open index.html in a browser. If it does not work directly, serve the folder locally with:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.

## How to receive submissions

Open index.html and find this line near the top of the form:

<form action="https://formsubmit.co/your.email@gmail.com" method="POST">

Replace your.email@gmail.com with your own email address. The first submission will trigger a confirmation email from FormSubmit; click the link inside it to activate the form.
